One-page statique, direction « minimalisme architectural » : Instrument Sans, mode clair et mode sombre, **12 langues** (FR par défaut ; EN, DE, ES, IT, NL, PT, RU, ZH, JA + AR et HE en écriture de droite à gauche), prise de rendez-vous avec calendrier, message, appel direct et WhatsApp, 6 réalisations en fiches avec galeries + un aperçu enrichi de 30 fiches de démonstration (images générées), animations discrètes.

```
eric/
├── index.html          # one-page (12 langues, clair/sombre)
├── css/style.css       # design system : Instrument Sans, minimalisme architectural
├── js/app.js           # i18n, modales, rendez-vous, galeries, effets
├── js/langs.js         # manifeste des 12 langues
├── js/demo-projects.js # les 30 fiches d'aperçu (images générées)
├── i18n/{fr,en,de,es,it,nl,pt,ru,zh,ja,ar,he}.json
├── img/                # photos Hustin Bâtiment (optimisées) + img/demo/ (images générées)
├── brand/              # brand book : 130 propositions de logo
├── docs/shots/         # captures pour le README
└── readme/             # README web (FR/EN) — readme.pdf à la racine
```
